# Preliminary Kuramoto alpha-sigma Analysis

## Empirical Results from World C
- sigma=0.3, alpha=0: K_c = 0.2597
- sigma=0.7, alpha=0: K_c = 0.6226
- sigma=1.0, alpha=0: K_c = 0.8861

## Mean-field Prediction Check (alpha=0)
For Gaussian g(omega) with std sigma:
K_c = 2/(pi * g(0)) = 2*sigma*sqrt(2/pi) ≈ 1.5958*sigma
